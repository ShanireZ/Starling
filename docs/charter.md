# Starling v2 立項文件

> **一句話**:裝在 GSX250R **車身側板(車把下整流罩)**上的一對**電子百葉進氣口("鰓口")**(固定框 + 聯動葉片),**開口朝車頭迎風**,隨車速開合——越快開得越大,像**張鰓呼吸**納入迎面氣流。**看得見的動態造型件;開口通透後迎風納氣,帶來附帶的氣流 / 散熱收益(溫和,非主目標)。**

立項日期:2026-06-25 · 名稱沿用 Starling(v1 同名專案已廢棄重新啟動)

---

## 0. 為什麼重新啟動:v1 的教訓

v1(摩托車主動空氣動力學系統)流產,四個失敗點其實是同一個病根的四張臉——**成本前置、收益後置,而收益天花板本來就低**:

| v1 失敗點 | 實質 |
|---|---|
| 設計過於複雜,逐漸流產 | 成本無限後拖,從未產出可用切片 |
| 成本 ≫ 收益(僅很小提升) | **真正死因**:250 摩托 <100km/h,主動氣動的下壓力收益微乎其微 |
| 結構複雜、不便偵錯觀察 | 燒錢過程中看不見盈虧 |
| 過於專業 | 鎖死在一個人腦子裡,無人能驗 |

**複雜本身不是罪,複雜配不上收益才是。** v2 由此立下兩道閘:

1. **立項前給收益封頂** —— 效能收益有限,故**以造型 / 動態炫酷為主目標**;鰓口迎風納氣帶來的氣流 / 散熱只當**附帶溫和收益**,把成本對齊"炫酷"這個可達又可觀察的價值,不為微小效能堆複雜度。
2. **第一週就要有看得見的縱切片** —— 用最小可觀察實物驗證,而非建幾個月才發現不值。

## 1. 專案身分

- **名稱**:Starling(沿用並重釋義——椋鳥 / 鳳凰,展翅母題)
- **平台**:Suzuki **GSX250R**(單車型起步,非通用支架)
- **形態(2026-06-25 大改 → 百葉式;2026-06-28 定位側板 + 開口朝車頭迎風)**:**車身側板(車把下整流罩)**上一對**電子百葉進氣口("鰓口")**——一個**固定的 U / 矩形結構框**(內凹、NACA 式觀感),框內一組**多片聯動百葉**,**開口朝車頭迎風**。低速齊平閉合,高速葉片張開露縫(戰鬥機 / F1 多段開縫層疊面的樣子)。
- **行為**:**速度越快 → 開度越大**(MCU 按速度驅動百葉角度);開口朝前,張開時像「張鰓呼吸」納入迎面氣流。
- **機構**:固定框承受風載;百葉 = **一個舵機 + 一根連桿帶動多片 = 1 個真實自由度**(汽車主動進氣格柵 / 空調出風口的成熟做法)。
- **氣動姿態(無害優先,收益封頂)**:① **開口朝車頭迎風**,低速齊平閉合(最低阻),高速張開像「張鰓呼吸」納入迎面氣流;② 固定框包住葉片邊緣(少抖振 / 哨音);③ **後側通透**(去死後壁、葉片張開氣流可從前側穿過進喉道→入車體內部·借真進氣口的觀感),**帶附帶的輕度進氣 / 散熱作用**,但**不做重型工程化涵道 / 冷卻系統**(無獨立 airbox·只求開口通透的納氣觀感與輕度穿流);高速張開會有少量增阻(迎風口納氣),在 <100km/h、小開口下視為**無害可接受**;**效能非主目標——收益封頂,不為它堆複雜度。**
- **無燈光**:視覺價值 = 這套隨速度開合的**動態** + 造型本身。

---

## 2. 定位與價值(收益封頂)

- **價值錨點**:視覺 / 動態炫酷("展翅感"),外行一眼能看懂
- **效能非主目標(收益封頂)**:迎風納氣有附帶氣流 / 散熱收益,但不做氣動調優、不堆效能向複雜度
- **場景**:100km/h 以內的日常騎行
- **ROI 閘門**:任何"為多一點效能 / 下壓力"的複雜度,預設砍掉

---

## 3. 控制架構(防戰線蔓延的生死線)

- **即時控制 100% 板載自包含**:MCU + 傳感器,本機決定翼面開度
- **外部連接(藍牙或有線)只做兩件事**:① 設定(模式 / 參數) ② 資料採集與回傳
- **外部端(手機 / PC / 網頁)不參與即時控制**
- **無雲、無 OTA、無跨學科集成**

---

## 4. 設計鐵律(v1 四大死因的對策)

1. **收益封頂** — 主價值是造型 / 動態炫酷;迎風納氣的氣流 / 散熱是**附帶溫和收益、非目標**;砍掉一切"為效能"的顯著複雜度。
2. **第一週可觀察縱切片** — 先做出"翼面隨某個輸入張合"的能看見的最小原型。
3. **單人可造、可調、可偵錯** — 不引入需專家 / 多人才能維護的結構。
4. **禁戰線蔓延** — 無 App 即時控制、無雲、無 OTA、無應變片效能回饋鏈、無多學科集成計畫。
5. **外行可讀** — 不懂的人看一眼就明白"它隨速度展翅,很酷"。

---

## 5. 範圍

### ✅ 做(In)
- **機械**:固定 U / 矩形框(兼車頭安裝支架)+ 多片聯動百葉 + 單舵機連桿
- **電子**:板載 MCU + 測速傳感 + 供電 + 舵機驅動
- **軟體**:板載即時控制邏輯(速度 → 開度)+ 極簡設定 / 資料介面(藍牙或有線)

### ❌ 不做(Out — 明確放棄,守住邊界)
- 主動下壓力優化 / 閉環氣動調參 / 借襟翼追升力
- **重型工程化涵道 / 主動冷卻系統**(開口通透有輕度穿流與附帶散熱,但不做獨立 airbox / 熱管理)
- 配套 App 即時控制 / 雲遙測 / OTA
- 應變片效能回饋鏈 / 五學科集成計畫(v1 的墳墓)
- 燈光

## 8. 後續網頁模型計畫(GSX250R 高仿真 · 待 owner 拍板啟動)

下一輪的網頁 3D 不再是示意方塊,而是**貼近真實 GSX250R 的高仿真**,目標"看著就像裝在真車上"。要做的:

1. **真車替換**:用接近 GSX250R 的車頭 / 整流罩 / 前輪比例替換當前佔位方塊(找參考圖 / 三視圖對齊尺寸)。
2. **進氣口落位**:把一對百葉涵道安到車頭兩側的真實位置,尺寸與車頭比例協調。
3. **葉片 / 涵道精修**:
   - 葉片做成有弧度(cambered)的翼型薄片而非平板;**前緣朝下**(氣流上偏 → 下壓力側,不升力);
   - 涵道做出 NACA 式內凹深腔的真實觀感(借觀感、非真穿流);
   - 片數 / 縫距 / 開度行程按視覺與"1 自由度聯動"定。
4. **交互保留**:車速 → 開度滑桿、滑鼠 orbit、視角預設;低速齊平 ↔ 高速張開。
5. **材質 / 配色**:貼近真實(車漆 + 金屬框 + 葉片),出一版能直接看效果的繪製。
6. **守住的約束**:1 自由度;固定框承風;造型為主、效能為輔(收益封頂,不堆效能複雜度);不做重型真涵道 / App / 雲。
