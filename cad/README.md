## 裝配順序(臺架)

1. 框軸孔壓入 8 只黃銅套(緊則用 HOLE_COMP 調大重打框,勿硬敲裂框);
2. 鋼軸卡進葉片背脊槽 + 環氧 AB 膠(粘接面砂紙打毛;尼龍粘不住 502/CA),居中(兩端各露 ≈12.5mm);
3. 葉片連軸從框內穿入兩側軸套;右側露出端壓上曲柄(過盈 + 環氧膠),**四隻曲柄臂必須同角度**(裝配時把葉片全部立到豎直位再粘曲柄);
4. M2 螺絲把四隻曲柄銷接到拉桿四孔(自攻進曲柄,拉桿孔為松孔,能自由轉動);
5. 舵機裝支架視窗(自帶自攻釘),支架用 2×M3 掛框右柱(豎槽可上下微調);
6. 球頭拉桿連舵機臂(取 8mm 孔位)與拉桿下端孔,**用易拉夾/球頭螺紋把長度調到:舵機中位 ≈ 葉片 50° 半開**;
7. 頂葉軸套扭簧(預緊朝閉合),斷電手感驗證:鬆手全組彈回閉合;
8. 框掛臺架座(下雙耳 M3 自攻進立柱),整機通電跑 `test` 命令掃角。

## 行程與韌體映射

- 機械行程:**閉合 = 10°**(微傾使相鄰葉鱗片式搭接,不是 0° 純豎直——純豎直相鄰葉尖會干涉)→ **全開 = 90°(水平)**;
- 韌體把 0-100% 開度映射到舵機脈寬 `us0..us90`:**臺架標定** `us0` = 葉片抵到閉合位、`us90` = 水平全開位(`set us0 / set us90` + `save`),CLOSED_DEG 的 10° 偏置被標定自然吸收,韌體無需改。
